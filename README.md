## TOMAP
A multi-criteria design-decision analysis (MCDA) tool implementing TOMAP (Trade-Off Matrix by Aggregated Preferences) via the A-FINE Aggregator. It combines multi-actor preference functions and multi-level performance information to evaluate predefined alternatives and produce preference-consistent design-decision valid trade-off matrices.
