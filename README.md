## TOMAP
A multidimensional, multi-criteria design-decision analysis (MCDA) tool implementing TOMAP (Trade-Off Matrix by 
Aggregated Preferences) through the A-FINE Aggregator. It integrates multi-actor preference functions and multi
level system performance information to evaluate predefined alternatives using A-FINE’s unique decision-valid 
preference aggregation. It produces preference-consistent trade-off matrices and transparent design-decision 
support.
